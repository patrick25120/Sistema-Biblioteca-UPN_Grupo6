# Sistema de Biblioteca UPN

## Descripcion
Sistema desarrollado en Python para administrar los libros
de la biblioteca de la UPN.

## Objetivo
Facilitar el registro, consulta, busqueda, modificacion y
eliminacion de libros, asi como la gestion de prestamos
y devoluciones.

## Tecnologias utilizadas
- Python
- Visual Studio Code
- Git
- GitHub

## Funcionalidades
- Validacion de acceso para estudiantes y bibliotecarios.
- Registro y consulta de libros.
- Busqueda de libros.
- Modificacion y eliminacion de libros.
- Gestion de prestamos y devoluciones.
- Ordenamiento por burbuja y seleccion.

## Estructura del proyecto
- Main.py
- acceso.py
- gestion_libros.py
- gestion_prestamos.py
- menu.py
- ordenamiento.py
- validaciones.py
